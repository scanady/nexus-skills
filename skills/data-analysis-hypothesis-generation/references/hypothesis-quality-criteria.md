# Hypothesis Quality Criteria

A framework for judging hypotheses. A robust one scores well across several dimensions — none needs to be perfect on all. In a report, put a comparative ratings table in the main text and the detailed strengths/weaknesses in the quality-assessment appendix.

## Core Criteria

| Criterion | Question it answers | Strong | Weak |
|-----------|---------------------|--------|------|
| **Testability** | Can it be tested empirically with current/near methods? | "protein X overexpression cuts proliferation >30%" | "influenced by complex interactions" |
| **Falsifiability** | What specific observation would disprove it? | "knock out gene X → phenotype Y disappears" | "may vary with context" (built-in escape) |
| **Parsimony** | Minimum entities/mechanisms needed? | one well-supported mechanism | several speculative steps piled on |
| **Explanatory power** | How much of the phenomenon does it account for? | explains multiple independent observations, quantitatively | explains only part; needs extra hypotheses |
| **Scope** | Range of contexts it covers? | generalizes across conditions/systems | narrow — acceptable if boundaries stated |
| **Consistency** | Aligns with established principles? | applies established mechanism in new context | contradicts well-supported findings without justification |
| **Novelty** | New insight beyond restating known facts? | new mechanism, reframing, non-obvious predictions | restates established facts |

Notes: simple ≠ simplistic — complexity is justified when evidence demands it; established mechanisms count as "simpler" than novel unproven ones. Consistency runs on a spectrum (fully consistent → mostly → partially inconsistent → highly inconsistent, the last requiring exceptional evidence). Novelty alone doesn't make a hypothesis valuable — it must still be testable, parsimonious, and explanatory.

## Comparative Evaluation

Hypotheses trade off (more parsimonious but less explanatory; broader but less testable now; more novel but less consistent). Approach: identify each one's strengths/weaknesses, decide which criteria matter most for *this* phenomenon, note which are most immediately testable and which would be most informative if supported.

**Distinguishability is the key question:** can an experiment tell competing hypotheses apart? Identify predictions that differ between them, prioritize those that make distinct predictions, and note which experiment most efficiently narrows the field. Consider that several could be partially correct.

## Pitfalls

- **Untestable** — too vague for specific predictions; invokes unmeasurable entities; needs non-existent technology.
- **Unfalsifiable** — escape clauses ("may or may not"); post-hoc explanations that fit any outcome.
- **Overly complex** — multiple unproven mechanisms; complexity not justified by explanatory gain.
- **Just-so stories** — plausible narratives with no testable/distinguishing predictions.

## Practical Loop

Draft mechanistic hypotheses → apply criteria to find weaknesses → refine for testability/clarity → develop specific predictions → compare systematically → prioritize for testing by distinguishability and feasibility. The goal is not one perfect hypothesis but a set of testable, falsifiable, informative ones that advance understanding.
