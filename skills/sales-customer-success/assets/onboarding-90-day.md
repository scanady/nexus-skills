# 90-Day Onboarding Checklist: {customer}

Segment {segment} | CSM {csm} | Kickoff {date} | Go-live target {date}
First-value deadline: {date}. Limit by segment: enterprise 30 days, mid-market 21, SMB 14.

## Gate rule

Hand off to steady-state CSM coverage on day 90 only if health is yellow or better and first value is proven. Otherwise extend onboarding and tell the sponsor why.

## Days 0-14: Set up

Before kickoff
- [ ] Read the contract and sales hand-off notes (pain, decision drivers, people)
- [ ] Confirm outcomes and success measures with the sales owner
- [ ] Prepare welcome pack and kickoff agenda; draft the success plan

Kickoff (days 1-2)
- [ ] Agree outcomes, measures, and timeline with sponsor and champion
- [ ] Map people: sponsor, champion, technical lead, user lead
- [ ] Set cadence and channels; book recurring sessions
- [ ] Agree the customer's time commitment in writing

Technical setup (days 3-10)
- [ ] Provision tenant, roles, and permissions; configure SSO if needed
- [ ] Connect integrations; migrate data and check it
- [ ] Train admins; train the core user group

## Days 15-30: Activate

- [ ] Check logins on day 15; chase silent users
- [ ] Reach the first business outcome milestone
- [ ] Hold the 30-day review and record the result
- [ ] Record the date first value was reached: {date}

## Days 31-60: Adopt

- [ ] Add features tied to outcome 2 and 3
- [ ] Bring live the remaining integrations
- [ ] Compare usage with peer accounts; share the benchmark
- [ ] Add a second department contact (multi-thread)

## Days 61-90: Prove

- [ ] Run an advanced use-case workshop
- [ ] Measure ROI in the customer's units and write it down
- [ ] Hold the 90-day executive review; confirm the next-year plan
- [ ] Score health; apply the gate rule; hand off

## Early-warning triggers (act the same week)

- No login by any user for 14 days
- Sponsor misses two sessions in a row
- First value not reached by the deadline
- Admin training not finished by day 14
