# Contributing to {Project Name}

Thank you for your interest in contributing to {Project Name}.

## How To Contribute

1. Open an issue before starting substantial work.
2. Create a focused branch for your change.
3. Add or update tests when behavior changes.
4. Update documentation when user-facing behavior changes.
5. Open a pull request with a clear summary and validation notes.

## Pull Request Checklist

- The change has a clear purpose.
- Tests, checks, or manual validation have been run.
- Documentation has been updated when needed.
- No secrets, local files, or generated artifacts are committed.
