# Security Policy

## Reporting A Vulnerability

Report security issues to {Security Contact}.

Do not open public issues for vulnerabilities. Include enough detail to reproduce the issue and assess impact.

## Response Process

1. The maintainers acknowledge the report.
2. The maintainers assess severity and affected versions.
3. A fix or mitigation is prepared.
4. The maintainers publish guidance when disclosure is appropriate.
