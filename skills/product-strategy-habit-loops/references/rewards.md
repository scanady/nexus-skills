# Variable Rewards

The phase that brings users back. Dopamine fires on the *anticipation of an uncertain* reward, not on receiving it — the brain craves the hunt. Predictable rewards decay; variability sustains engagement. Autonomy is essential — forced or manipulative rewards backfire.

## Reinforcement Schedules

Skinner's four, by when the reward comes:

| Schedule | Reward after | Behavior | Product use |
|----------|--------------|----------|-------------|
| Fixed ratio | set # of actions | steady, pause after reward | milestone/completion bonuses |
| **Variable ratio** | random # of actions | **highest, most sustained** | feed refresh, likes, loot boxes |
| Fixed interval | set time | slow start, ramps near reward | daily login, weekly digest |
| Variable interval | random times | steady, moderate | push notifications, "new content" |

Variable ratio is the "slot machine effect" — each action might be *the one*, no predictable pause, resistant to extinction. Successful products combine schedules (Instagram: variable-ratio likes + variable-interval feed + fixed-ratio post flow + fixed-interval 24h stories).

## Three Types

**Tribe (social)** — validation, status, belonging from others (likes, upvotes, endorsements; variable in who/when/how many). Patterns: show *who* engaged, notify on validation, social proof, status hierarchies. Risk: anxiety, comparison, painful rejection.

**Hunt (resources)** — the search for information, money, or goods (feeds, deals, discovery; you never know what you'll find). Patterns: infinite scroll, varied feeds, personalized-with-surprise recs, pull-to-refresh. Risk: compulsive checking, FOMO, endless consumption.

**Self (mastery)** — competence, completion, consistency (streaks, XP, achievements; variable difficulty). Patterns: progress bars, streaks, achievement unlocks, completion celebrations. Risk: hollow achievements, streak anxiety, completion ≠ real value.

## Designing Them

1. **Connect reward to core value** — random dopamine without value breeds regret (learning app rewards skill validation, not just confetti).
2. **Preserve autonomy** — "you might also like…" (optional), never "you must complete X to continue."
3. **Vary the type, not just the frequency** — mix Tribe/Hunt/Self.
4. **Balance anticipation and delivery** — too little frustrates; too much habituates.
5. **Tie reward to effort** — earned beats free.

Checklist per reward: genuinely valuable? variable? connects to an internal trigger? user has autonomy? loads the next trigger? which type?

## Timing & Loaded Triggers

Immediate (core action completion — like animation), short delay (build anticipation), scheduled (routine), accumulated (encourage return). The best rewards **load the next external trigger**:

| Action | Reward | Loaded trigger |
|--------|--------|----------------|
| post content | likes/comments | engagement notification |
| complete profile | matches shown | match notification |
| create playlist | "made for you" | new-music notification |

## Mistakes & Measurement

Mistakes: predictable rewards, rewards unconnected to value (feel hollow), over-gamification (feels like work), removing autonomy (resentment), one reward type only, delayed core reward (user leaves first), rewards without investment (low retention).

Measure: time in reward phase (rising), return rate after reward (higher = working), organic sharing/screenshots (reward worth showing), session length, completion rate (self-reward effectiveness).
