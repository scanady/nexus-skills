# Neuroscience Foundations

The brain science under the Hook Model — dopamine, reinforcement schedules, the habit loop, and where ethical design draws the line.

## Dopamine and Anticipation

**Dopamine is released in anticipation of reward, not on receiving it.** The brain craves the pursuit, not the prize; unpredictability heightens the response; certainty reduces it (habituation).

```
Trigger → anticipation (dopamine spike) → action → reward → new baseline
```

When the reward is **predictable**, the spike shifts to the trigger and fades over time. When it's **variable**, the spike is maintained through action and never fully habituates.

## Reinforcement Schedules

Skinner's four (fixed/variable × ratio/interval). **Variable ratio** — reward after a random number of actions — is the strongest for sustained behavior: each action might be "the one," there's no predictable pause, and it resists extinction. **Variable interval** (rewards at unpredictable times) drives steady checking (email, feeds). Variable beats fixed on every axis: behavior continues instead of stopping, dopamine is maintained instead of habituating, and the loop is never "done."

## The Habit Loop in the Brain

Cue → routine → reward, run repeatedly, moves control from the deliberative **prefrontal cortex** to the automatic **basal ganglia**:

```
Early:  cue → prefrontal cortex (deliberation) → decision → action → reward
Habit:  cue → basal ganglia → automatic action → reward   (no deliberation)
```

Implication: initial engagement needs motivation + ease; habitual engagement runs on autopilot.

## Emotions as Internal Triggers

The limbic system uses emotion as a cue — the amygdala stores emotional memories, the hippocampus links emotion to context. When a product consistently resolves a negative emotion, the brain associates that state with the product, the emotion becomes an internal trigger, and use becomes automatic. Products that address emotional states form stronger habits than purely functional tools.

## Tolerance & Escalation

**Hedonic adaptation** — the same reward yields diminishing dopamine, so more intensity is needed for the same effect. The exploitative response is escalation (more notifications, more content, more intensity). The sustainable response is depth (better notifications, better-matched content, more meaningful rewards) — vary the reward *type*, connect to genuine value, build in natural limits.

## Uncertainty & Social Reward

**Information-gap theory** — uncertainty creates tension the brain is driven to close; curiosity is intrinsically motivating (notification badges, feed refresh, mystery rewards). Optimal uncertainty sits between "too predictable → boring" and "too random → frustrating."

**Social reward** activates the same regions as physical reward — likes trigger dopamine, rejection activates pain centers, status gains raise dopamine/serotonin while status threats raise cortisol. This is why follower counts, leaderboards, and public recognition are so powerful — and so risky.

## Ethical Implication

Work *with* the brain, don't exploit it: use the dopamine understanding to deliver genuine value and resolve emotional needs sustainably; align rewards with the user's goals, not engagement for its own sake. The tell:

| Ethical | Exploitative |
|---------|--------------|
| user achieves their goal | user just spends time |
| feels satisfied after | feels empty after |
| chooses to engage | feels compelled |
| genuine value | manufactured urgency |

Research roots: Schultz (dopamine prediction error), Skinner (reinforcement schedules), Graybiel (basal ganglia and habits).
